# 用户手册

## 角色

| 角色 | 主要权限 |
|---|---|
| 系统管理员 | 用户、备份、统计、MFA；无审计日志查看权 |
| 数据分析员 | 采集、风险、规则编辑与发布 |
| 口岸操作员 | 内网旅客录入、导入、风险匹配和布控建议 |
| 审计员 | 只读审计日志查询与导出 |
| 只读用户 | 态势、事件、风险和地图查看 |

连续 5 次密码或动态码失败锁定 15 分钟。密码至少 10 位，并同时包含大小写字母、数字和特殊字符。浏览器 30 分钟无操作会话超时。

## 互联网端

1. “数据采集”查看六个适配器，可修改 URL、周期、启停或手动运行。
2. “疫情事件”按关键字和等级过滤并导出 CSV。
3. “风险研判”查看六因子、国家排行、区域趋势和预警；模型权重合计必须为 100%，保存后生成新草稿，再到规则页测试和发布。
4. “全球展示”打开 92vh 地图；切换风险、气泡、热力、中转和人员流图层，拖动真实 14 日时间轴，点击国家下钻，导出 PNG。
5. “数据摆渡”选择文件、消息队列或 API outbox，以及全量/增量任务。所有指标来自真实任务；互联网端不会反向探测内网。

## 信息源与大语言模型

两侧管理员都可进入“系统管理 → 大语言模型”，新增供应商并选择协议、服务地址和密钥；保存后先点“获取模型”，选择或手工填写模型，再点“连接测试”。启用“本平台默认模型”只影响当前一侧系统，另一侧需要独立配置。

互联网端“数据采集”允许新增、编辑、停用和删除信息源。用户可选择固定间隔，或填写五段 Cron 表达式并选择计划时区；解析方式可选内置、大语言模型或混合解析。使用模型解析时，需选择已启用供应商、模型，并可填写提取提示词。所有设置保存到数据库并立即更新调度，不需要改代码。

预设源是首次初始化的起点，用户可直接调整或补充更广的信息源。切回“内置结构化解析”会清除该源的模型引用；仍被信息源引用的供应商不能删除。事件详情中的“模型研判”会调用本平台当前默认模型，未配置时页面会明确提示。

## 内网端

内网展示与互联网镜像一致，并增加口岸图层、旅客预警和接收中心。

- 单人录入：填写证件、姓名、国籍、14 日来源地、中转、口岸、航班和健康申报。
- 批量导入：UTF-8 CSV/JSONL，导入后立即返回脱敏结果。
- 自动目录：口岸系统把规范文件放入配置目录，后台自动处理。
- 旅客列表只显示脱敏姓名、证件尾号和加密联系方式状态；明文只在请求处理内存中出现。
- 选择旅客后可生成按机场、海港或陆路区分的结构化措施和法律依据。
- 数据接收中心支持目录扫描、RabbitMQ、人工包导入；API 轮询只有配置启用后才显示。

## 管理员首次 MFA

1. 使用本地管理员登录。
2. 进入“系统管理 → 双因素认证”。
3. 在离线 TOTP 认证器录入页面密钥，输入 6 位码启用。
4. 系统清除当前会话；重新登录时填写动态验证码。

密钥只显示一次。遗失时由另一名已完成 MFA 的管理员在用户页重置。LDAP/AD 用户密码必须在目录系统修改。
